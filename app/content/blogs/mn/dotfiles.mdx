Олон жилийн турш хөгжүүлэлтийн орчноо тохируулж, сайжруулсны эцэст бүх зүйлээ нэг [dotfiles repository](https://github.com/daze17/dotfiles)-д цэгцэлсэн. Энэ нийтлэлд би өдөр тутам ашигладаг хэрэгслүүд болон тэдгээрийн тохиргооны талаар ярих болно.

![dotfiles](/blog/dotfiles/dotfiles.svg)

# Яагаад Dotfiles?

Тохиргооны файлууд (dotfiles) нь таны хөгжүүлэлтийн орчныг тодорхойлдог. Тэдгээрийг version control-д хадгалснаар та:

- **Компьютер хооронд sync хийх** - Ажлын болон хувийн компьютер дээр ижил тохиргоо
- **Хурдан сэргээх** - Эвдрэл эсвэл шинэ төхөөрөмж ашиглах үед бүх зүйлийг дахин суулгах
- **Хөгжүүлэлтийг хянах** - Ямар нэг зүйл эвдэрвэл буцаах

Би dotfiles-аа [GNU Stow](/blog/gnu_stow) ашиглан удирддаг.

# Хэрэгслүүд

Тохиргоонд орсон зүйлс:

- [**Neovim**](/blog/neovim) - Үндсэн код editor
- [**tmux**](/blog/tmux) - Терминал мультиплексер
- **Kitty/Ghostty** - Терминал эмуляторууд
- **yabai + skhd** - [Гарын товчлуур дээр суурилсан](/blog/keyboard_driven) цонх удирдлага
- **Zsh + Oh My Zsh** - Shell орчин

# Shell Тохиргоо

Би `.zshrc` тохиргоогоо ер нь бол маш энгийн байдлаар хадгалагдсан. Гол хэсгүүд нь:

```bash
# Theme
ZSH_THEME="robbyrussell"

# Plugins
plugins=(git zsh-autosuggestions)

# Editor
if [[ -n $SSH_CONNECTION ]]; then
  export EDITOR='vim'
else
  export EDITOR='nvim'
fi

# vim-ийг nvim руу чиглүүлэх
alias vim="nvim"
```

Би **Oh My Zsh**-ийг одоогын байдлаар зөвхөн хоёр plugin-тай ашигладаг:
- `git` - git alias болон prompt мэдээлэл
- `zsh-autosuggestions` - команд санал болгох

Үлдсэн хэсэг нь version manager-үүдийг удирддаг: Node.js-д **NVM**, Ruby-д **RVM**, бусад хэрэгслүүдэд **Mise**.

# Neovim

[Neovim](/blog/neovim) бол миний код бичих цагийн ихэнх хэсгийг өнгөрүүлдэг газар. Миний тохиргоо Lua ашигладаг бөгөөд дараах зүйлсийг агуулдаг:

- Олон хэлний LSP дэмжлэг
- Telescope - fuzzy finding
- Treesitter - syntax highlighting
- Үр ашигтай ажиллахын тулд тусгай keybinding-үүд

Тохиргоо нь `~/.config/nvim/` дотор байрладаг. Бүрэн мэдээллийг [Neovim нийтлэл](/blog/neovim)-ээс үзээрэй.

# Терминал: Kitty & Ghostty

Би Kitty-г олон жил ашигласан бөгөөд саяхан Ghostty-г туршиж эхэлсэн. Хоёуланд нь:

- **Тусгай өнгөний схем** - dark/light theme солих боломжтой
- **Код бичихэд тохирсон фонт** тохиргоо
- **Гарын товчлуурууд** - split болон tab-д зориулсан

Theme солих нь symlink-ээр удирдагддаг - `theme.conf` нь `dark-theme.auto.conf` эсвэл `light-theme.auto.conf` руу заадаг. Ингэснээр өдрийн цагаар light theme оройн цагаар dark theme автоматаар солих боломжтой.

# Цонх Удирдлага: yabai + skhd

macOS дээр **yabai** автоматаар цонх байрлуулдаг бол **skhd** систем даяарх hotkey-үүдийг хангадаг. [Гарын товчлуур дээр суурилсан ажлын урсгал](/blog/keyboard_driven)-г уншиж үзэхийг зөвлөж байна.

Түгээмэл ашигладаг товчлуурууд:

```bash
# Цонхонд фокус хийх
alt - h : yabai -m window --focus west
alt - l : yabai -m window --focus east
alt - j : yabai -m window --focus south
alt - k : yabai -m window --focus north

# Цонх зөөх
shift + alt - h : yabai -m window --swap west
shift + alt - l : yabai -m window --swap east
```

# tmux

Терминал session удирдахад [tmux](/blog/tmux) маш амар байдаг. Тохиргоонд:

- Vim хэв маягийн pane navigation
- Хулганы дэмжлэг идэвхжүүлсэн
- Тусгай status bar
- Prefix key дахин тохируулсан


Хэрэгсэл бүрийн тохиргоо нь бие даасан бөгөөд тус тусад нь stow хийхэд хялбар.

# Эхлэх

Эдгээр dotfiles-ийг ашиглахын тулд:

```bash
# Repo-г clone хийх
git clone https://github.com/daze17/dotfiles.git ~/dotfiles

# GNU Stow суулгах
brew install stow

# Package-үүдийг тус тусад нь stow хийх
cd ~/dotfiles
stow nvim
stow tmux
stow kitty

# Эсвэл бүгдийг нь stow хийх
stow */
```

# Төгсгөлд нь

Dotfiles repo ашиглах нь шинэ компьютер ашиглах эсвэл эвдрэл гэмтлээс сэргээх үед маш их хэрэг болдог аргачлал юм. Зөвхөн `.zshrc` болон editor тохиргоогоо хянах нь ч үнэ цэнэтэй.

Миний [dotfiles](https://github.com/daze17/dotfiles)-аас санаа авч болно. Та ч бас өөрийн dotfiles-г тохируулж ашиглаад үзээрэй.
