Neovim бол миний үндсэн код засварлагч. VS Code, JetBrains IDE болон бусад хэрэгслүүдийг туршиж үзсэний дараа би Neovim-ийн хурд, [гарын товчлуур дээр суурилсан ажлын урсгал](/blog/keyboard_driven) болон хязгааргүй тохируулах боломжийн улмаас буцаж ирсээр байна.

<img src="/blog/neovim.png" alt="neovim" style={{ width: '50%' }} />

# Яагаад Neovim?

- **Хурд** - Шууд нээгддэг, том файлуудыг удаашралгүй ажиллуулдаг
- **Гар дээр суурилсан** - Home row-оос хэзээ ч салахгүй
- **Тохируулах боломжтой** - Бүх зүйлийг Lua-гаар тохируулж болно
- **Зөөврийн** - Neovim суулгасан аль ч машин дээр ижил тохиргоо ажилладаг

# Тохиргооны Бүтэц

Миний тохиргоо модуль бүтэцтэй:

```
~/.config/nvim/
├── init.lua
├── lua/
│   ├── core/
│   │   ├── options.lua
│   │   ├── keymaps.lua
│   │   ├── autocmds.lua
│   │   └── lazy.lua
│   └── plugins/
│       ├── ui.lua
│       ├── navigation.lua
│       ├── completion.lua
│       ├── editor.lua
│       ├── git.lua
│       ├── formatting.lua
│       ├── treesitter.lua
│       └── lsp/
└── lazy-lock.json
```

Энэ салгалт бүх зүйлийг цэгцтэй байлгадаг - үндсэн тохиргоо нэг газар, plugin-ууд функцээр бүлэглэгдсэн.

# Plugin Manager: lazy.nvim

Би plugin удирдлагад [lazy.nvim](https://github.com/folke/lazy.nvim) ашигладаг:

- Plugin-уудыг шаардлагатай үед lazy load хийх
- Автомат суулгалт
- Давтагдах тохиргооны lock файл
- Update удирдах цэвэрхэн UI

# Theme: Rose Pine

[Rose Pine](https://rosepinetheme.com/) colorscheme "moon" хувилбартай нь цэвэрхэн, нүдэнд таатай харагдал өгдөг:

```lua
{
  "rose-pine/neovim",
  name = "rose-pine",
  config = function()
    require("rose-pine").setup({
      variant = "auto",
      dark_variant = "moon",
    })
    vim.cmd("colorscheme rose-pine")
  end,
}
```

# Навигаци

## Telescope

[Telescope](https://github.com/nvim-telescope/telescope.nvim) бол миний навигацийн ажлын урсгалын гол хэсэг - бүх зүйлд зориулсан fuzzy finder:

```
Space + sf        Файл хайх
Space + sg        Live grep (текст хайх)
Space + sh        Help tag хайх
Space + sk        Keymap хайх
Space + Space     Buffer солих
Space + /         Одоогийн buffer дотор fuzzy хайлт
Space + s.        Сүүлийн файлууд
Space + sn        Neovim тохиргоо хайх
```

## Neo-tree

Файлын мод навигацид [Neo-tree](https://github.com/nvim-neo-tree/neo-tree.nvim) sidebar explorer өгдөг:

- `Space + e` - Файлын мод нээх/хаах

# Completion: nvim-cmp

[nvim-cmp](https://github.com/hrsh7th/nvim-cmp) эдгээр эх сурвалжуудаас autocompletion хийдэг:

- **LSP** - Language server completion
- **LuaSnip** - Snippet expansion
- **Path** - Файлын зам completion

Товчлуурууд:

```
Ctrl + n/p        Item хооронд шилжих
Enter             Сонголт баталгаажуулах
Ctrl + Space      Completion идэвхжүүлэх
Ctrl + l/h        Snippet дотор үсрэх
```

# LSP Интеграци

Language Server Protocol дэмжлэг нь:

- Definition руу очих
- Reference олох
- Hover documentation
- Symbol нэр солих
- Code action

LSP тохиргоо `lua/plugins/lsp/` дотор server-ийн тусгай тохиргоотой байрладаг.

# Git Интеграци

## Lazygit

`Space + lg` нь [Lazygit](/blog/lazygit)-ийг floating terminal-д нээдэг - commit, branch болон төвөгтэй git үйлдлүүд хийх миний дуртай арга.

## Gitsigns

[Gitsigns](https://github.com/lewis6991/gitsigns.nvim) inline git статус харуулдаг:

- Нэмсэн/өөрчилсөн/устгасан мөрүүдэд gutter дээр тэмдэг
- `]c` / `[c` - Hunk хооронд үсрэх
- Editor-оос гарахгүйгээр stage, reset, preview хийх
- Одоогийн мөрийн blame

# Editor Сайжруулалтууд

## Which-key

`Space + ?` боломжтой keybinding-үүдийг харуулдаг - команд олоход зайлшгүй шаардлагатай.

## Mini.nvim

Жижиг боловч хэрэгтэй модулиудын цуглуулга:

- **mini.ai** - Илүү сайн text object (`a"`, `i(` гэх мэт)
- **mini.surround** - Хүрээлэх тэмдэгт нэмэх/өөрчлөх/устгах
- **mini.statusline** - Цэвэрхэн status bar

## Autopairs

Хаалт, хашилт болон бусад хос тэмдэгтүүдийг автоматаар хаадаг.

## Trouble

`Space + xx` илүү сайн diagnostics panel нээдэг - алдаа, анхааруулга, TODO-ууд нэг газар.

# Formatting

[Conform.nvim](https://github.com/stevearc/conform.nvim) хадгалахад formatting хийдэг:

```lua
formatters_by_ft = {
  lua = { "stylua" },
  typescript = { "prettierd", "prettier" },
  typescriptreact = { "prettierd", "prettier" },
}
```

# Treesitter

[Treesitter](https://github.com/nvim-treesitter/nvim-treesitter) дараах зүйлсийг хангадаг:

- Нарийн syntax highlighting
- Илүү сайн code folding
- Incremental selection
- Syntax дээр суурилсан text object

# Үндсэн Keymap-үүд

Plugin-үүдээс гадна эдгээр үндсэн mapping-үүд өдөр тутмын ашиглалтыг сайжруулдаг:

```
Ctrl + h/j/k/l    Split хооронд шилжих
Ctrl + s          Файл хадгалах (insert mode-д ч ажилладаг)
Esc               Хайлтын highlight арилгах
Space + pv        netrw нээх
Space + tn        Шинэ tab
```

# AI: Supermaven

[Supermaven](https://supermaven.com/) AI-д суурилсан код completion өгдөг - Copilot-оос хурдан, илүү сайн context ойлголттой.

# Эхлэх

Миний тохиргоог ашиглахын тулд:

```bash
# Одоо байгаа тохиргоог нөөцлөх
mv ~/.config/nvim ~/.config/nvim.bak

# Dotfiles clone хийж stow хийх
git clone https://github.com/daze17/dotfiles.git ~/dotfiles
cd ~/dotfiles
stow nvim

# Neovim нээх - plugin-ууд автоматаар суугдана
nvim
```

# Сурах Зөвлөмжүүд

1. **Үндсэн motion-уудаас эхэл** - `hjkl`, `w`, `b`, `e`, `0`, `$`
2. **Нэг plugin-ийг сайн сур** - Telescope-ийг эзэмшээд дараа нь нэмээрэй
3. **Which-key ашигла** - `Space` дараад сонголтуудыг хүлээ
4. **Аажмаар тохируул** - Нэмж байгаа зүйлээ ойлго

Тохиргоо нь миний [dotfiles](/blog/dotfiles) дотор байгаа - [GNU Stow](/blog/gnu_stow) ашиглан [tmux](/blog/tmux) болон бусад тохиргоонуудтай хамт удирддаг.
